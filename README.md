# SYSU Researcher Skills

AI agent skills for Sun Yat-sen University (SYSU) research workflows, built on top of OpenCLI.

## Overview

This repository provides AI agent skills that combine SYSU's digital resources (JWXT, LMS, Library) via OpenCLI plugin commands into coherent research workflows.

## Prerequisites

- OpenCLI installed and configured
- `opencli-plugin-sysu` installed
- Chrome logged into SYSU services (JWXT, LMS, Library)
- `opencli doctor` green for COOKIE/UI adapters

## Skills

- `sysu-course-planning`: Course selection and schedule planning
- `sysu-library-research`: Library database and catalog research
- `sysu-lms-study`: LMS-based study workflow
- More coming...

## Usage

```bash
# Install
npx skills add .
```
